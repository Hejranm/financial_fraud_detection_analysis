## Power BI Dashboard

This folder contains the Power BI dashboard for the Financial Fraud Detection Analysis project.

**Requirements:**
- Microsoft Power BI Desktop must be installed to open and explore the `.pbix` file.

**How to use:**
1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file using Power BI Desktop.

**Note:** The dashboard file is provided for exploration and further analysis.
